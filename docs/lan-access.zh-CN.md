# 局域网访问

使用 Apache 同时提供版本目录入口和受管理项目入口。只需配置运行 Flaragon 的电脑；使用该电脑的局域网 IP。

## 版本目录入口

在“环境设置 → PHP 运行设置”中，为需要的 PHP 启用目录入口，填写 HTTP 端口、根目录及监听 IPv4 地址。内部起始端口供 FastCGI 使用，与浏览器访问的 HTTP 端口分别设置。目录入口只提供服务和配置。

根目录可点击“选择目录”选择本机文件夹，也可填写盘符绝对路径，例如 `E:\sites`；相对路径按 Flaragon 环境根目录解析。已有项目不需要搬入软件目录。

## 受管理项目入口

1. 在“环境设置 → 网站服务与默认 PHP”设置项目入口端口，选择本机网卡 IPv4 监听地址。`127.0.0.1` 仅供本机；具体网卡地址同时保留回环监听。
2. 添加项目，填写独立的访问标识，点击“选择目录”选择本机项目目录，或手填绝对路径，例如 `E:\work\shop`。网站入口目录填写项目内相对路径，并选择 PHP 版本。CakePHP 常见入口为 `webroot`，旧版也可能为 `app/webroot`；按实际结构填写，留空则使用项目目录本身。
3. 勾选“启用项目访问”和“允许局域网访问”；需要出现在导航页时勾选“在导航页展示”。隐藏导航项仍可通过已知路径访问。
4. 保存应用并启动 Apache。“打开项目导航页”可预览入口；“复制导航页地址”用于分享统一入口，“复制地址”用于分享选中项目。地址来自已保存的配置。

示例：监听地址为 `192.168.1.50`、入口端口为 `8080`、项目标识为 `shop` 时，导航页为 `http://192.168.1.50:8080/`，项目为 `http://192.168.1.50:8080/shop/`。示例地址和端口不代表当前机器配置。

“启用域名虚拟主机”默认关闭。需要额外域名入口时才开启并填写域名，域名解析由使用者配置，不影响 IP 路径入口的使用。

项目显示名称和 PHP 版本变化不改变访问标识。修改访问标识会改变链接；项目切换 PHP 不会改写应用配置或数据。

## 本机防火墙与网络

Flaragon 不自动修改防火墙。若系统阻止入站连接，由使用者在本机 Windows Defender 防火墙的高级设置中添加入站规则，限定为当前使用的 Apache 可执行文件、启用的 TCP HTTP 端口、实际适用的网络配置文件以及所在的源网段。使用管理员权限完成系统要求的操作；无需开放 PHP 内部端口、MySQL 或 Redis，也无需关闭防火墙。

电脑 IP 变化后，停止 Apache，刷新组件并重新选择地址，再应用和启动；重新复制链接。软件无法解除公司网络或无线网络的设备隔离。

## 应用检查

受管理项目按配置的网站入口目录映射。检查路由、静态资源、登录跳转及上传 URL 是否保留 `/访问标识/` 前缀；使用自定义重写时检查 `RewriteBase` 与实际入口一致。软件不自动修改项目的 `.htaccess`、CakePHP 配置或业务文件。

多项目需要使用适当的 Session Cookie 名称和路径，避免登录状态互相影响。具体行为以应用版本和自定义配置为准。

浏览器使用局域网 IP 访问网站时，PHP 仍在 Flaragon 所在电脑执行，连接同机数据库可继续使用回环地址，无需将数据库 host 改成局域网 IP。MySQL 8.0.13 及以上同时监听 `127.0.0.1` 和 `::1`，支持应用使用 `localhost`；MySQL 5.7 及早期 8.0 当前仅监听 `127.0.0.1`。完整停止对应 MySQL 后，用包含双回环支持的程序启动即可更新受管监听配置；不改动应用连接参数或数据库数据。
